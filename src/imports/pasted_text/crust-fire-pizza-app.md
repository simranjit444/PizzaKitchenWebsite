Create a modern, premium, visually appealing **pizza cloud kitchen ordering website and mobile-responsive web app**.

### Brand Concept

The brand is a modern pizza cloud kitchen focused on freshly made, cheesy, delicious pizzas delivered directly to customers. The design should feel **fresh, bold, youthful, premium, and appetizing**, while keeping the ordering experience extremely simple.

Create a fictional brand called **“Crust & Fire”**.

### Visual Style

* Modern food-tech aesthetic
* Premium but affordable feeling
* Clean white/cream backgrounds
* Use deep charcoal/black for text
* Use warm red/orange as the primary brand accent
* Use subtle yellow/cheese tones as secondary accents
* Large, high-quality pizza photography
* Rounded cards and buttons
* Soft shadows
* Generous spacing
* Bold modern typography
* Minimal but attractive animations
* Avoid an overly complicated design
* Make the website feel like a real commercial pizza brand

### Responsive Design

Design for:

* Desktop: 1440px
* Tablet: 768px
* Mobile: 390px

The mobile experience is extremely important because most customers will order from their phones.

Make:

* Product cards responsive
* Sticky mobile cart/order button
* Easy thumb-friendly controls
* Large CTA buttons
* Simple checkout
* Mobile-friendly filters

### Interactions

* Cart → Checkout

* Order confirmation → Order tracking
* Header cart icon → Cart

### Important UX Requirements

The ordering process should require as few steps as possible.

Target flow:

**Home → Choose Pizza → Customize → Add to Cart → Checkout → Payment → Order Tracking**

Make the food photography the visual focus.

Use realistic pizza images with melted cheese, fresh toppings, crispy crust, and warm lighting.

The final design should look like a **real, launch-ready pizza delivery brand**, not a generic Figma template.

Create all pages and reusable components in a consistent design system with polished spacing, typography, responsive layouts, and realistic content.
